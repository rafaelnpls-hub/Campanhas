CENTRAL DE CAMPANHAS - APP ANDROID WEBVIEW

Este projeto abre a página inicial local (index.html) em uma WebView.
Os botões Conta Chave e Varejo navegam para:
- https://campanhacc.netlify.app/
- https://campanhavj.netlify.app/

COMO GERAR O APK NO ANDROID STUDIO
1. Abra a pasta CentralCampanhasAndroid no Android Studio.
2. Aguarde a sincronização do Gradle e instalação do SDK solicitado.
3. Vá em Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. O APK será criado em app/build/outputs/apk/debug/app-debug.apk.

Para um APK de distribuição, use Build > Generate Signed App Bundle / APK e assine com sua chave.
